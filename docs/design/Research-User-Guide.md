# FluoAxis 科研工程版使用说明

本版本只供科研工程验证。Method/Data Contract 和 Golden 保持未批准草案，不用于临床诊断、治疗或患者管理。

## 启动与工作区

在完整内部发布目录运行 `FluoAxis.App.exe`，不要只复制 EXE。需要 Windows 11 x64 和本机 WebView2 Runtime；.NET、Windows App SDK 和 XBF/PRI 窗口资源由内部自包含包携带。当前为未签名工程构建，不代表正式安装包资格。

窗口使用 Per-Monitor V2 DPI 感知，文字和控件由 WinUI 按显示器的实际缩放比例绘制。升级后请退出旧进程，再从新构建目录启动；仅替换 DLL 或继续使用旧窗口不会改变进程 DPI 模式。无需修改系统缩放、图形缩放或兼容性设置。跨显示器移动应交由系统和 WinUI 自动处理，图形的科研坐标与数值不随显示 DPI 改变。

已提交的运行自动保存在本机工作区。左侧分析工作台显示阶段状态，顶部选择已有项目或新建项目。窗口关闭前会等待活动操作结束，未提交的孔板/映射编辑会要求处理。异常关闭后从上次已提交事务恢复，可在“设置与诊断”查看恢复状态。

顶部“项目管理”集中放置切换、新建和工程包操作；打开运行后收起，项目名称与未提交提示保持可见。青蓝边框标出当前步骤，主按钮执行当前任务；绿色只表示流程/QC完成，阳性和阴性不会靠红绿暗示好坏。失败和建议动作显示在阶段摘要下方。方法身份与详细计算值可按需展开，“查看计算”会自动展开对应证据。

## 从原始文件到结果

1. 点击顶部“导入并自动判读”，或拖入单个原始文件。选择文件后自动建立项目，无需先新建空项目。
2. 默认使用已确认的“四角对照 · B2–G11 样本区”：A1 为 100% 阳性、A12 为 NTC、H1 为 WT、H12 为 LQC；B2–G11 共 60 孔可放样本，其他 32 孔忽略。只分析实际测得的样本孔，不要求填满样本区；四个对照必须都存在。
3. 通道、时间单位、解析规则与孔位明确时，软件按顺序完成映射、孔位、校准、对照质控和样本分析，进入结果页。可展开“识别依据与孔位方案”核对识别来源；不会按荧光高低猜对照身份。
4. 只有孔号时，以孔号作为本次样本编号、每孔独立判读。文件明确提供完整 SampleId/Replicate 时保留文件信息；不复制上次实验的样本编号。需要合并重复孔时使用后续设置，先核对样本关系。
5. 单位不明、通道冲突、缺对照或显式样本信息不全时，自动流程停止并显示原因。补齐设置后点击“确认设置并继续自动分析”。QC 失败时保留失败证据；INVALID 不能作为阴性解释，重复孔冲突不得用均值掩盖。

“设置固定孔位”可保存新方案并设为默认；区域支持 `B2-G11` 矩形写法，完整矩形会用此简写显示。解析规则在勾选后展开。初始四角方案只在无保存方案时创建，不覆盖之后的设置。摘要分别显示样本、忽略和未定义孔；未定义孔不会被自动忽略。若文件只写 `Time` 而没有单位，应在方案中明确选择时间单位及解析规则，不能根据数据大小猜分钟或秒。自动识别使用有界前缀；超出识别范围时转人工映射，完整导入仍执行原有验证。

“仅导入预览”保留本次已选编码、分隔符、小数格式和时间单位；FAM/ROX 工作表、表头、时间列、孔列和结束行均可修改，界面行列从 1 开始，证据中的 source index 从 0 开始。孔板支持多选批量编辑与撤销/重做，“应用选中孔位方案”也可作为一次整体编辑撤销。已完成运行可点击“从此文件重新设置”，复用源文件建立新的项目/Run；原结果保留。新运行或切换步骤从页面顶部展示，当前步骤内的滚动阅读不受普通刷新打断。

结果页的“实际计算来源”包含来源/映射/输入 hash、端点与计算窗口，分页显示已保存值。旧工程缺少的字段明确显示缺项，当前方法仍为未批准科研草案。

## 数据与图形

当前 Run 的原始数据按孔读取。Explorer 支持双通道、二维/三维列映射、点选身份、研究派生公式、视觉平滑与编辑覆盖。原始 RFU 不可修改，派生数据不参与正式判读。视图可保存后恢复；三维相机遵循固定方向模式。两点距离是所选显示坐标的几何距离，不是 BRAF 判读结果。

点击图中数据点会选择对应表格行；选中表格行会高亮对应图点，包含第二序列。筛选与排序后仍按原始点身份联动。清空表格选择恢复所有点的正常显示。单次联动最多 10,000 个图点，超过时保留表格选择并提示缩小范围。

PNG/SVG 保存当前图形；二维少于 10,000 点可导出矢量 SVG，三维或密集数据图请使用 PNG。离线 HTML 包含当前页冻结数据与内置绘图资源；不是完整 Run 报告，也不访问远端绘图服务。选择图形前应核对列、单位、页范围和 raw/derived 标记。

“数据与图形”使用独立大视区：顶部仅保留项目身份、数据选择与图形工具，导入和项目管理返回“分析工作台”操作。“放大图形”收起标题与数据选择，再次点击“还原布局”恢复。

“视图设置”打开浮层，内含坐标、研究处理、表格整理及保存/恢复视图；关闭设置即可返回完整图形。“数据表与选点”按需查看表格和来源。浮层不缩小画布，图形自动填满可用窗口；无需向下滚动寻找坐标轴。图形类型和测距放在工具栏，导出格式和报告附图位于更多菜单。

若一个孔的所有 RFU 值相同，曲线为水平线，这是原始数据的正确呈现。图形渲染器缓存位于本机应用数据目录，安装目录保持只读可用。

## 报告与工程包

“报告与导出”先读取冻结快照，再输出 HTML、XLSX 或 PDF 技术草稿。核对 Report ID、Run revision、Method/算法版本及完整性标记。`storedComplete` 只说明工程来源字段完整，不说明科学方法已批准；`storedPartial`/`unavailable` 表示历史缺项。

报告页依次显示运行核对、快照复核和保存操作。PDF 是主要输出按钮，Excel/HTML 为并列次级选择；保存区固定在页底。当前运行修订变化后旧快照提示会清空，导出仍由后端验证实际已提交内容。

“另存工程包”输出单项目/Run及原始源副本。“打开工程包”验证内容后导入；相同身份已存在时拒绝覆盖。工程包包含实验内容，应按实验室数据管理要求处理。使用不同工作区验证移动后可重开，不能通过改名绕过身份冲突。

## 故障处理

操作失败后先读取安全错误码、建议与当前 Run 状态，不反复创建新项目替代原记录。“设置与诊断”可以导出技术支持包，只含受限运行环境和事件代码，不含源文件、Raw RFU、项目名称或异常堆栈。磁盘空间不足、缺 WebView2 或权限错误需要先修正环境；已有已提交结果保留。

科学批准、真实仪器格式资格、整机性能、辅助技术与离线发布验收状态以本构建对应的变更记录和需求矩阵为准。
